# RetinoNet 🧿
AI-Powered Retinopathy Detection from Fundus Images

## 🚀 Overview
RetinoNet is an intelligent diagnostic tool designed to assist in the early detection of diabetic retinopathy using retinal fundus images.
Built on deep learning foundations, it provides a user-friendly platform to:
1.Upload retinal scans
2.Instantly receive diagnostic feedback
3.Manage past screening records
The primary mission is to enable accessible, accurate, and scalable retinal disease screening — aiding in timely intervention and reducing the risk of vision loss.

## ✨ Features
🔬 Instant Diagnosis: Upload fundus images and receive predictions in real-time
🧠 Deep Learning Model: Powered by Convolutional Neural Networks (CNNs)
🔐 User Accounts: Secure login and signup system
🗃 Report History: Easily view and manage previous diagnostic results
💡 Modern Frontend: Sleek and responsive UI built with React & Next.js
🌐 Robust Backend: Deep learning model served via Flask or Express.js
🔄 Scalable Architecture: Designed for practical deployment and extensibility

## 🛠 Tech Stack
- **Deep Learning:** TensorFlow / Keras
- **Frontend:** React.js / Next.js
- **Backend:** Flask/express.js
- **Other:** Git LFS for managing large model files
